# RecruitBox - AI Prompt Log

## Prompt 1 - Project Planning
Plan a recruitment platform MVP called RecruitBox with candidate and recruiter workflows. Include job browsing, job applications, candidate tracking, recruiter dashboard, applicant filtering and hiring status management.

## Prompt 2 - Application Architecture
Design a simple React/Vite architecture for RecruitBox with public candidate routes and protected recruiter routes. Use Supabase for authentication, database and storage.

## Prompt 3 - Candidate Application Flow
Build a candidate application flow where users can view job details, submit their name, email, phone, experience, location, cover note and resume, then receive an application tracking ID.

## Prompt 4 - Recruiter Dashboard
Build a recruiter dashboard showing applicant counts by hiring status and provide navigation to applicant management.

## Prompt 5 - Applicant Search and Filters
Add applicant search and filtering by candidate name/email, job, status, years of experience and location. Show a useful empty state when no applicants match.

## Prompt 6 - Candidate Status Management
Allow recruiters to view candidate profiles and update hiring status between Applied, Under Review, Shortlisted, Interview, Selected and Rejected.

## Prompt 7 - AI Resume Summary
Add an AI-assisted resume summary feature that generates a concise recruiter-facing summary using available candidate and application information. The feature should be assistive and should not make autonomous hiring decisions.

## Prompt 8 - Responsive UI
Improve the RecruitBox interface for desktop and mobile screens with responsive layouts, consistent spacing, readable typography and usable form controls.

## Prompt 9 - Validation and Edge Cases
Add validation and useful error states for missing resumes, invalid email addresses, invalid tracking IDs and searches or filters with no matching results.

## Prompt 10 - Testing and Documentation
Review the RecruitBox MVP for candidate flow, recruiter flow, responsive behavior, edge cases and documentation requirements. Prepare the project for final demo and submission.
