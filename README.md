# RecruitBox

RecruitBox is a recruitment platform MVP that connects candidates with recruiters through a simple hiring workflow.

## Features

### Candidate
- Browse available jobs
- View job details
- Apply for a job
- Upload resume
- Receive application tracking ID
- Track application status

### Recruiter
- Secure recruiter login
- View recruitment dashboard
- View and search applicants
- Filter applicants by job, status, experience and location
- View candidate profiles
- Update candidate status
- Shortlist candidates
- Generate AI-assisted resume summaries

## Hiring Statuses

- Applied
- Under Review
- Shortlisted
- Interview
- Selected
- Rejected

## AI Feature

RecruitBox includes an AI-assisted resume summary feature for recruiters. 
The summary provides concise candidate information and a recommendation based on the available application data.
